Frequently asked questions

Quick notes about using these tools.

Are these calculators free?

Yes. This demo page does not require an account or payment to use its calculators.

Are currency rates exact?

No. Rates are reference values returned by an external service and may differ from rates offered by banks, card providers, or money exchangers.

Does the website save my inputs?

This single-file demo does not send calculator inputs to a server. Currency conversion does make a request to retrieve exchange-rate data.

Can I add more calculators?

Yes. You can extend the tool cards and add another calculator definition in the JavaScript section.
